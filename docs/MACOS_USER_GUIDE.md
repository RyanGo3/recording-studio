# 土豆工厂 Mac 使用说明

适用版本：v2.1.1｜整理日期：2026 年 11 月 25 日

这份说明面向已经拿到 Mac 成品 ZIP 的使用者。解压安装即可使用，不需要执行打包命令，也不需要安装 Python、FFmpeg 或 Homebrew。录制电脑里的声音时，需要另外安装并配置 BlackHole 2ch；只做视频转换、压缩、剪辑和声音柔化时不需要它。

## 一、先选对安装包

本次成品要求 **macOS 15.0 或更新版本**。

点击屏幕左上角苹果菜单 →「关于本机」，查看系统版本和芯片：

| 你的 Mac | 对应文件 |
| --- | --- |
| “芯片”显示 Apple M 系列 | `PotatoFactory-v2.1.1-macos-arm64.zip` |
| “处理器”显示 Intel | `PotatoFactory-v2.1.1-macos-x86_64.zip` |

两个包分别适配对应架构，请选择与电脑匹配的版本。

## 二、安装与首次打开

1. 把对应的 ZIP 文件复制到 Mac。
2. 在 Mac 的访达中双击 ZIP，等待完整解压。建议在 Mac 上解压，以保留应用内部文件结构。
3. 将解压得到的 `PotatoFactory.app` 拖入「应用程序」文件夹。
4. 从「应用程序」双击打开。系统授权列表中的名称可能显示为 PotatoFactory 或土豆工厂。

当前版本使用临时签名，尚未进行 Apple Developer ID 签名和公证。如果系统提示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”，确认文件来自作者且未被修改后：

1. 先尝试打开一次应用。
2. 打开「系统设置 → 隐私与安全性」，向下找到本应用的拦截提示。
3. 点击「仍要打开」，按提示确认。

如果提示应用“已损坏”或“会损坏电脑”，请先核对下载是否完整、包是否匹配，保留提示截图反馈作者；不要把这些提示一律当作普通的开发者验证提示。

## 三、允许录制权限

第一次录制时，按系统提示授权。如果之前点过拒绝，可到「系统设置 → 隐私与安全性」调整：

- **屏幕录制**：录屏需要。不同系统版本可能显示为「屏幕与系统音频录制」等名称，找到本应用并允许。
- **麦克风**：采集麦克风或 BlackHole 音频输入时需要允许。

修改权限后，完全退出土豆工厂，再重新打开；仅关闭窗口可能不够。第一次使用建议先做一段 10 秒测试，检查画面、声音和保存文件。

## 四、要录电脑声音，先配置 BlackHole

“系统声音”指浏览器、播放器、游戏等电脑正在播放的声音。本版本通过 **BlackHole 2ch** 采集，驱动不随应用附带。

### 1. 安装 BlackHole 2ch

打开 BlackHole 官方安装说明，从其中的下载入口取得 **2ch** 版本安装器，按图形安装向导完成安装。安装前关闭正在使用声音的应用；安装器要求重启时，先重启电脑。

官方安装说明：

`https://github.com/ExistentialAudio/BlackHole/wiki/Installation`

请选择 BlackHole 2ch。本版本按这个设备名称识别系统音源，只有 16ch 或 64ch 版本不能代替。

### 2. 创建多输出设备

多输出设备让声音同时送到扬声器或耳机和 BlackHole，这样你能听到声音，软件也能录到。

1. 打开「应用程序 → 实用工具 → 音频 MIDI 设置」。也可用 Spotlight 搜索「音频 MIDI 设置」。
2. 如果没有设备列表，在菜单「窗口」中打开音频设备窗口。
3. 点击左下角「+」，选择「创建多输出设备」。
4. 勾选实际使用的扬声器或耳机，以及 **BlackHole 2ch**。
5. 将参与设备的采样率尽量统一为 **48,000 Hz**。
6. 按 BlackHole 官方建议，将内建输出或实际使用的双声道播放设备设为主设备／时钟源；为其余设备开启「漂移校正」，主时钟设备不勾选漂移校正。
7. 可将多输出设备重命名为「土豆录音输出」，方便识别。

请创建「多输出设备」，不要误选成「聚集设备」。遇到设备顺序、音视频无法播放等问题，可对照官方配图检查。

官方多输出设备配置说明：

`https://github.com/ExistentialAudio/BlackHole/wiki/Multi-Output-Device`

### 3. 设置系统声音路由

打开「系统设置 → 声音」：

- **输出**：选择刚创建的多输出设备，例如「土豆录音输出」。
- **输入**：如果需要录制自己的讲话，选择实际麦克风，例如 MacBook 麦克风或外接麦克风。

保持默认输入为实际麦克风。混录时，软件会分别读取 BlackHole 和默认麦克风。

播放一段有声音的视频，确认自己能听到，再进行测试录制。仅仅安装 BlackHole、让软件找到设备，还不能保证电脑声音已经送入它；播放应用如果单独指定了输出设备，也要检查其设置。

录制完成、不再需要系统声音采集时，可以把系统「输出」切回原来的扬声器或耳机。下次录系统声音前，再切回多输出设备。

## 五、第一次录屏

1. 打开「录屏与录音」页面。
2. 选择「全屏」或「区域」。「全屏」录制主显示器；「区域」点击「框选区域」，拖出范围，按 Enter 确认，Esc 取消。
3. 按需求选择声音：

| 界面音源 | 录入内容 | 准备工作 |
| --- | --- | --- |
| 系统声音 | 电脑播放的声音 | BlackHole 2ch、多输出设备和音频权限 |
| 系统 + 外部 | 电脑声音和你的讲话 | 上述配置，加实际默认麦克风 |
| 仅外部 | 麦克风声音 | 默认输入选实际麦克风，允许麦克风权限 |

4. 选择保存目录，按需输入文件名。第一次测试建议先关闭画面效果。
5. 点击开始录制。主窗口隐藏后，可使用悬浮控制条暂停、继续、改名或停止。
6. 停止后等待显示保存完成，再查看成品。录像输出为 MP4。

首次建议录 10 秒：播放一点电脑声音，需要混录时再说一句话，停止后回放确认。录制期间保持声音设备、显示器布局和缩放设置稳定。

## 六、只录电脑声音，不录画面

1. 先完成 BlackHole 和多输出设备配置。
2. 在「录屏与录音」页面选择「仅录音」。
3. 选择保存位置，输入文件名，点击开始。
4. 播放需要录下的内容，结束后停止，等待 MP3 保存完成。

**当前「仅录音」固定录制系统声音，不录麦克风。** 如果只想录自己的讲话，可用「全屏」或「区域」配合「仅外部」先录成视频，再通过「视频转音频」提取音频。

电脑上其他应用的播放声音也可能一起录入，包括通知提示音。录制前可关闭不需要的声音来源。

## 七、保存位置与文件名

默认保存位置为当前用户的「影片 → 土豆工厂」，路径为 `~/Movies/土豆工厂`。也可以在软件内另选有写入权限、空间充足的本地目录。

- 文件名留空时，程序按录制开始时间自动命名。
- 录制中可改名；开始保存后名称锁定。
- 同名文件会增加 `_02` 等编号，避免覆盖。
- 录制和生成效果会产生临时素材，预留空间应大于最终成品大小。
- 自动缩放、平滑光标、电影感画面在停止后处理，长录像保存时间会更长。

## 八、剪辑、转换和声音处理

- **裁剪与导出**：打开现有 MP3／MP4，定位并添加切分点，导出多个片段；视频也可单独导出 MP3 音轨。
- **视频转音频**：添加视频，选择 MP3、M4A、WAV 或 FLAC，选择目录后开始转换。默认提取第一条音轨。
- **视频压缩**：添加视频，选择 H.265 或 H.264，以及清晰优先、均衡、体积优先，输出 MP4。重新压缩不保证一定变小，原文件保留。
- **声音柔化**：添加音频或视频，选择「高音角色」或「整段柔化」，设置强度后处理。只导出处理后的音频，不会直接修改原视频。

Mac 版请使用页面里的「添加文件」、目录选择器或「输入路径」。粘贴时使用完整的文本路径；Finder 原生文件拖入尚未接入。

录制和媒体处理不能同时进行，等待当前任务完成后再开始另一项。

## 九、常见问题

**提示找不到 BlackHole 2ch**

确认安装的是 2ch 版本，并能在「音频 MIDI 设置」看到它。安装器要求重启时完成重启，再重新打开软件。

**自己能听到，录下来却没声音**

检查系统输出是否为包含实际播放设备和 BlackHole 2ch 的多输出设备；确认播放应用没有绕过它，检查麦克风权限，再做短录音测试。

**录得到电脑声音，但没有自己的讲话**

录屏选择「系统 + 外部」；在系统声音设置中把默认输入改为实际麦克风并检查权限。「仅录音」模式本身不录麦克风。

**使用多输出设备后，音量键不能调音量**

多输出设备存在这一系统限制。可在「音频 MIDI 设置」中调整支持音量控制的单个设备，或先切回实际扬声器／耳机调好音量，再恢复多输出设备。

**混录有回声或杂音**

可改用耳机，避免扬声器声音再次进入麦克风；检查采样率和漂移校正。声音失真时先降低输入增益，关闭降噪做对比。

**录屏黑屏、画面不对或区域偏移**

检查屏幕录制权限，授权后退出并重开应用。当前仅支持主显示器，布局或缩放改变后重新框选。受保护内容不保证能录制。

**悬浮控制条出现在录像里**

当前 Mac 版控制条可能被录入。可把控制条移出所选区域，或缩小录制范围避开它。

**停止后一直在生成**

画面效果需要逐帧处理，先等待保存完成。下次可关闭不需要的效果，减小录制区域，使用空间充足的本地磁盘。

**提示保存失败或程序异常退出**

记录错误提示和会话目录，保留原始素材与日志。隐藏会话目录中的视频分段、`system.wav`、`microphone.wav` 等可能用于恢复；程序目前没有一键恢复界面。反馈时附上系统版本、芯片、操作步骤和提示截图。

## 十、当前 Mac 版的使用范围

- 支持主显示器全屏及其内部区域，不支持跨屏区域。
- Retina 录像按逻辑分辨率导出，不是屏幕原始物理像素分辨率。
- 光标效果使用箭头形状，不区分文本光标；点击效果可能受系统输入监控权限影响。
- 当前成品已通过 Apple Silicon 和 Intel Mac 云端构建、界面启动、随包工具编码及文件完整性检查。
- 实际屏幕采集、BlackHole 路由、麦克风混录和长时间音画同步仍需在使用者的 Mac 上验证。正式长录前先完成短录制回放检查。
