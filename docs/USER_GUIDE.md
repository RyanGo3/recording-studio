# 土豆工厂使用说明

作者：大土豆|Ryan

## 安装和启动

新版免安装包完整解压后，双击 `PotatoFactory.exe`。不要直接在压缩包内运行，也不要只复制 EXE 而漏掉 `ffmpeg.exe`、`ffprobe.exe`。旧版 `RecordingStudioV2.exe` 不包含本轮更新。

保存位置应选择当前账户有写入权限、空间充足的本地目录。录制过程中会产生临时视频、未压缩 WAV 和效果中间文件，瞬时空间占用会高于最终 MP4。

## 添加文件与选择目录

- 声音柔化、视频转音频和视频压缩共用一个素材区，空白时显示拖放提示，添加后显示文件队列。点「输入路径」展开输入框，粘贴完整路径后回车或点「添加路径」；「粘贴添加」可直接读取 Windows 资源管理器复制的文件、文件夹或「复制文件地址」的多行路径。带引号、中文、空格和下划线均可。剪辑页保留单文件路径输入框。
- 将文件或文件夹从资源管理器拖入当前工具页面即可添加；批量工具中的目录仅扫描本层支持的文件，不递归子目录，并自动去重。超过一万项的目录会提示选择更小的目录。
- 「添加文件」选择器支持 Ctrl / Shift 多选，也可用「添加当前目录」。地址栏可粘贴完整目录后回车定位；粘贴完整文件路径可定位或直接点击「打开文件」。
- 录制保存位置和三个批量工具的保存目录均可直接输入、粘贴完整路径，或把文件夹拖到目录输入框。可输入尚未创建的目录，开始任务时创建。片段导出选择器同样支持地址栏粘贴目录后直接确认。
- 剪辑页一次打开一个文件，多文件会提示改用批量工具；粘贴或拖入一个目录会打开已定位该目录的文件选择器。录制页拖入单个文件可进入剪辑页；拖入一个目录则设置录制保存位置。
- 输入框支持 Ctrl+A、Ctrl+V 及右键菜单；焦点位于文件列表或页面空白处时，Ctrl+V 可直接添加剪贴板中的文件。处理或录制期间添加 / 拖入会提示等待。

Windows 原生拖放需要资源管理器与软件运行在相同权限级别；建议直接双击启动软件。

## 录制系统声音

1. 选择「系统声音」模式。
2. 选择保存目录，可以提前输入文件名。
3. 按需要打开或关闭「声音降噪」。录音乐、游戏音效等强调保真的内容时可关闭。
4. 点击开始录制，需要时暂停 / 继续。
5. 停止后等待保存完成，在剪辑页预览或导出。

此模式只录默认播放设备，不录麦克风。浏览器、播放器、聊天提示音会合并到同一文件。

## 录制屏幕

1. 选择全屏或选定区域。区域框选时按 Enter 确认、Esc 取消。
2. 选择音源：系统声音、系统 + 外部声音、仅外部声音。
3. 在 Windows「设置 → 系统 → 声音」中确认默认输出 / 输入设备。
4. 按需要打开自动缩放、平滑光标、电影感画面，并设置缩放倍率。
5. 点击开始。主窗口隐藏，屏幕边缘出现可展开的控制条。
6. 使用控制条暂停、继续、改名或停止；停止后等待画面效果生成完成。

效果在停止后处理，长录像或高分辨率画面需要更长时间。保存中退出会等待完成。缺少麦克风或无权限时会报错，不会静默切换到其他音源。

## 命名

留空时自动生成带录制开始时间的名称。可以录制中改名；保存开始后名称锁定。同名文件使用 `_02` 等编号，避免覆盖已有文件。

文件名不能包含 Windows 非法字符或保留名称。扩展名由当前媒体类型决定，录音为 `.mp3`，录像为 `.mp4`。

## 预览和剪辑

- 录制完成后自动进入剪辑页，也可打开现有 MP3 / MP4。
- 点击或拖动时间轴定位，左右方向键前后移动 5 秒，Home / End 跳到开头或结尾。
- 在当前位置添加切分点，或输入 `01:23`、`01:23:45`。
- 导出片段会按切分点生成多个文件；可移除不需要的切分点。
- 视频可单独导出 MP3 音轨。

这是基础片段切分工具，不支持多轨剪辑、字幕、转写、逐镜头手工调整或任意时间段拼接。MP3 按最近的帧边界切分；视频优先流复制，必要时转码，不能保证任意切点都达到逐帧无损精度。

## 声音柔化

1. 点击侧栏「声音柔化」，添加一个或多个文件；也可在剪辑页点击「声音柔化」，使用当前录音或录像。
2. 选择「高音角色」或「整段柔化」，设置强度与导出格式。
3. 点击「开始柔化」。每个文件独立处理，单个失败不会中断其他文件；可随时取消。
4. 在文件列表选择已完成的文件，点击「原声」和「柔化后」试听同一段、不超过 30 秒的音频。两版自动匹配平均音量，方便比较音色；只调整试听，不对成品作整体降音量。
5. 成品默认保存到录制页保存目录下的「声音柔化」文件夹，也可填写独立保存目录；点击「输出文件夹」打开。MP3 成品可直接进入剪辑页。

**高音角色**自动寻找明显偏高的周期性发声，只在识别片段动态削弱突出的刺耳声和齿音，片段边缘平滑过渡。它按声音特征判断，可能同时影响其他高音说话者；没有检测到目标时提示失败，不会自动改成整段处理。**整段柔化**在整个音频范围内检测和动态处理，会影响所有说话者及背景声音。

默认强度 55，支持 15–100；强度越高，刺耳声与齿音抑制越明显，也可能损失明亮度。保留低频和主体音量，不再固定把整段声音压低。处理不改台词与语速，不进行重新配音、变声或精确人声分离。与「声音降噪」是独立功能，录制完成后按需使用。

支持 MP3、WAV、M4A、FLAC、AAC、OGG、OPUS、WMA、AIF、AIFF，以及 MP4、MKV、MOV、WEBM、AVI 中的第一条音轨。每个输入不超过 2 GB；录像只导出柔化后的音频，不改变视频。导出支持 MP3、24 位 WAV、FLAC；保留单声道 / 立体声，更多声道转立体声，MP3 采样率最高 48 kHz。

每次导出使用新名称，保留原文件与以前的成品，并附带两段试听和 JSON 处理记录。取消后保留已完成的成品，当前未完成的临时文件自动清理。柔化期间不能开始录制，避免试听声音混入录音；退出时取消剩余任务并等待当前处理结束。

## 视频转音频

1. 点击侧栏「视频转音频」，添加一个或多个视频；剪辑页的「视频转音频」可带入当前录像。
2. 选择 MP3、M4A、WAV 或 FLAC，可单独选择输出目录。
3. 点击「开始转换」，完成后选择列表中的成品并点击「打开成品」或「输出文件夹」。

默认保存到录制保存目录下的「视频转音频」文件夹。MP3 使用高品质可变码率，M4A 为 AAC 192 kbps，WAV 为 24 位 PCM，FLAC 为无损编码。WAV / FLAC 保留解码后的音质，不能修复原片已有的有损压缩。默认提取第一条音轨，保留其完整时长；MP3 最多双声道、最高 48 kHz。没有音轨时会明确提示。

支持 MP4、MKV、MOV、AVI、WEBM、WMV、FLV、M4V、MPG、MPEG、TS、MTS、M2TS、3GP 等 FFmpeg 可读取的视频。不限制输入为 2 GB，文件通过 FFmpeg 流式处理，适合大视频。

## 视频压缩“减肥”

1. 点击侧栏或剪辑页的「视频压缩」，添加视频。
2. 默认选择「H.265 · 高效压缩」和「清晰优先」。需要更广的播放兼容性时选择 H.264。
3. 若希望进一步缩小，改用「均衡」或「体积优先」。默认保留原分辨率与帧率，不通过缩小画面、降低帧率来减肥。
4. 点击「开始压缩」。完成后查看原大小、成品大小和减少比例，打开成品对比观看。

压缩使用慢速编码和固定质量模式：H.264 三档 CRF 为 18 / 23 / 28，H.265 为 20 / 24 / 28。数值越低保留的细节越多，但体积通常也更大。重新编码有损，实际效果取决于源片；已经压缩充分的视频可能不变小，此时界面会标记「未缩小」，不会把增大误报为减肥成功。原片和成品均保留，可自行比较。

输出为 MP4，默认保存到录制目录下的「视频压缩」文件夹，也可自选目录。保留第一路视频和全部音轨；适合 MP4 的 AAC / MP3 / ALAC / AC3 / EAC3 音轨直接复制，其余音轨转为 AAC。字幕、附件和其他视频轨不导出，有此需求时请保留原片。奇数尺寸会补一行或一列以符合编码器要求。HDR 输入需选择 H.265；该工具没有专业 HDR 母版、动态元数据和无损转码验收。

两个工具均支持批量任务、逐项进度、单个失败后继续和取消。每次成品使用新名称，原文件不变。取消后保留已完成成品和本次未完成文件；隐藏的 `.media_job_*` 目录保存 FFmpeg 日志、进度与成品校验记录，未完成的文件不应当作完整成品。退出时取消剩余任务并等待编码器结束。为保证录制和试听不受影响，视频处理、声音柔化与录制不能同时启动。

## 异常恢复

异常时记下提示中的隐藏会话目录，先复制整个目录保留备份。

| 文件 | 用途 |
| --- | --- |
| `original.mp4` | 已合并的原始录像（如果流程已经执行到该步骤） |
| `video_*.mp4` | 暂停前后的原始视频分段 |
| `system.wav` / `microphone.wav` | 对应音源的原始采样 |
| `*_aligned*.wav` | 已按视频时长对齐的音轨 |
| `cursor.json` | 效果配置及光标轨迹 |
| `*.log` | FFmpeg 或渲染诊断日志 |

异常发生阶段不同，文件不一定齐全。成功保存后本次临时目录会自动清理；最终 MP3 / MP4 不在该临时目录内。程序没有一键恢复界面，必要时可结合日志和 FFmpeg 手工恢复。

## 常见问题

**找不到 FFmpeg**：免安装包需保留同目录 `ffmpeg.exe`；源码版放到 `tools\ffmpeg.exe`，或运行 `scripts\prepare-tools.ps1`。

**柔化提示缺少 FFprobe**：运行 `scripts\prepare-tools.ps1` 同时准备 `ffmpeg.exe` 和 `ffprobe.exe`；免安装包需保留两者。

**没有声音**：确认录制时默认播放设备确实在输出声音；不要录制中切换设备。麦克风录屏需检查 Windows 麦克风权限与默认输入设备。

**声音失真、杂音**：先关闭降噪比较原始效果，降低输入增益并确认音源本身无爆音；当前降噪不能修复严重硬件噪声或缺失采样。

**录像黑屏**：受保护内容不保证可录；确认区域位于有效显示器范围，显示器缩放或布局变更后重新选择区域。

**保存慢**：画面效果需要逐帧处理；可以关闭不需要的效果、减小录制区域，并选择本地磁盘。

**杀毒软件提示**：该版本 EXE 未购买代码签名证书。请从所有者的 GitHub Release 下载，使用随包校验文件比对；不要随意关闭系统防护。
