# 架构与最小运行代码

## 11 个运行模块

| 模块 | 职责 |
| --- | --- |
| `app.py` | Tkinter 主窗口、模式与状态、系统 MP3 录音、文件选择、播放预览、切分与导出 |
| `apple_ui.py` | 主题、图标、圆角卡片、按钮、开关和时间轴等界面控件 |
| `audio_sources.py` | 默认系统 / 麦克风设备解析，独立线程采样，PCM WAV 与大文件 RF64 |
| `audio_processing.py` | FFmpeg 高通、轻度频谱降噪、延迟补偿与限幅过滤器参数 |
| `audio_softening.py` | 高音片段识别、声道联动动态频谱衰减、分块重建、取消、校验与平均电平匹配试听 |
| `softening_ui.py` | Tkinter 声音柔化页面、批量队列、进度、错误与对比播放，复用主窗口事件队列 |
| `media_conversion.py` | 视频元数据探测、四种音频导出、H.264 / H.265 压缩、进度轮询、取消、校验与诊断记录 |
| `conversion_ui.py` | 视频转音频 / 视频压缩页面，复用批量任务界面、格式设置、独立输出目录及大小对比 |
| `path_inputs.py` | 统一素材队列与空态、路径解析、批量目录导入、剪贴板文件读取、路径 / 目录控件和 Windows 原生文件拖放 |
| `recording_v2.py` | 录屏会话、分段、暂停计时、音轨对齐、混音、输出命名和素材恢复 |
| `cinematic.py` | 原生鼠标轨迹、点击缩放计划、光标平滑、逐帧画面增强和并行渲染 |

`assets/studio.ico` 用于构建 EXE 图标。运行中的界面图标和控件背景通过 Pillow 动态绘制，不依赖外部图片素材。测试、说明、构建脚本不参与正常启动。

## 数据流

```text
Tkinter 主线程：用户操作 → 状态更新 → 轮询事件队列
                                      ↑
录音工作线程：WASAPI loopback → PCM / MP3 编码 → MP3

录屏工作线程：FFmpeg gdigrab → 暂停分段 → 视频拼接
              WASAPI 独立音源 → WAV → 时长对齐 → 混音
              鼠标采集 → 轨迹 / 点击 → 镜头计划 → 效果画面
                                               ↓
                                      H.264 / AAC MP4
```

Python 使用子进程调用外部 FFmpeg；声音柔化使用 FFprobe 读取并校验音频信息。界面线程通过队列接收开始、处理进度、成功与错误，避免编码工作直接阻塞 Tkinter 事件循环。

柔化线程逐个处理输入，SciPy 分块分析基频，使用 Hann STFT 重叠相加重建与声道联动动态衰减；检测刺耳声和齿音，软拐点和进入 / 恢复时间控制，目标区外直接使用原始样本。FFmpeg 输出成品及同时间范围、RMS 匹配的试听。默认强度 55，2.1 版起已不对应原工具固定均衡与整体降增益参数；不依赖原项目目录或浏览器服务。试听使用独立 mixer 通道，切页与录制前停止播放。实现与 GitHub 参考见 `SOFTENING_AND_UI_REFERENCES.md`。

视频工具使用独立工作线程和 FFmpeg 子进程，视频逐个流式处理，不把整段视频读入内存。`-progress` 输出与错误日志写入本次专属目录，工作线程定期读取进度并检查取消标志；取消会终止并等待子进程。主线程通过 `media_job` 事件分发至对应页面。转码后用 FFprobe 校验音视频轨和时长，独占保留成品名称后提交文件，避免覆盖既有成品。

Windows 拖放使用 `SetWindowSubclass` / `WM_DROPFILES`，为主窗口和选择器的现有 Tk HWND 注册。原生回调只读取路径、释放 HDROP 并入队，Tk 定时轮询按鼠标落点和当前页面分发；关闭前撤销子类及定时任务。目录输入框优先接收目录，其余位置导入当前工具。无需额外 Tcl / Tk 扩展或第三方拖放包。剪贴板在显式粘贴时读取 CF_HDROP 或文本，路径保留空格和下划线；批量目录导入只扫描本层，最多检查一万项。

压缩采用慢速 CRF 模式，不主动缩放和降帧，兼容音轨直接复制。返回实际字节数与缩小比例，不假设重编码必然缩小；输入无音轨仍可压缩，但转音频会明确报错。录制及三种后台工具互斥，窗口关闭等待取消结束。

## 生命周期

主界面按空闲、录制、暂停、停止和处理等状态管理按钮。暂停不计入输出时间轴；每段音频按实际视频时长修正，开始 / 恢复时重新对齐。超过 4 GiB 的原始 WAV 自动切换 RF64 头，支持长会话。

输出使用独占创建和同名编号，尽量避免覆盖已有文件。正常完成后清理本次隐藏会话目录；失败时保留中间文件和日志。硬件初始化仍可能引入少量音画误差。
