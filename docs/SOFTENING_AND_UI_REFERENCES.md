## 柔化引擎 2.0

旧版在目标片段持续削减 2.8 / 4.8 / 7.8 kHz，并附加整体增益下降，容易把柔化变成“变暗、变小声”。新版自行实现分块 STFT 动态频谱衰减：

- 约 32–46 ms 的 Hann 窗，四倍重叠与归一化重建；每批最多 128 帧，不把整段音频载入内存。各采样率取最接近 32 ms 的二次幂窗长。
- 以 100–1800 Hz 的主体能量为参照，检测 2.2–5 kHz 刺耳成分和 5–12 kHz 齿音；不足阈值时不持续削减。6 dB 软拐点，快速进入、缓慢恢复，控制状态跨批次延续。
- 平滑频率曲线、衰减上限和双声道联动；保留频谱相位与立体声比例。1600 Hz 以下不施加频谱增益衰减。
- 高音模式沿用基频目标识别，在目标边缘做 65 ms 渐变；作用区外直接使用原始解码样本。它不是声纹识别，仍可能同时影响其他高音说话者。
- 导出不再附加整体降音量；峰值限幅提高到 0.98，关闭自动增益。转码、多声道转双声道与防削波仍可能造成样本变化。
- 原声与柔化试听取相同时间段，按两者中较低的 RMS 电平衰减匹配，不提高任何一版音量。使用相同的限幅和编码设置。RMS 匹配并不等于所有声音的主观响度完全相同，也不是 LUFS 归一化。
- JSON 记录处理方式、频段衰减、整体 RMS 变化、试听匹配增益和原有校验结果。

强度默认 55，范围 15–100。更高会更明显地抑制刺耳声与齿音，也可能损失明亮度；宜用匹配音量的试听比较。处理不改变音高、台词、语速，不进行生成式重新配音。

## 文件区与界面

三个批量页面共用 `FileQueue`：一个素材区在拖放提示和文件队列之间切换；文件计数、添加、当前文件、移出列表、剪贴板添加和可展开路径输入集中在同一张卡片。移出列表只改任务队列。

保留 Windows 原生拖放、目录本层导入、多路径、中文、空格、下划线、引号与目录输入。隐藏的控件在窗口构造时就创建，以保持原生拖放注册。

主色改为暖白和苔绿，加入土豆播放图标；录制、剪辑和三个工具共用主题。主要执行操作位于工具页首，设置使用紧凑分段选项、自绘可键盘操作的强度滑条和细进度条。小窗口继续支持滚动访问全部设置和结果。
