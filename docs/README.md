| --- | --- |
| Mac 安装和日常使用 | [Mac 简易说明](MACOS_QUICK_START.md) |

| Windows 安装和使用 | [Windows 使用说明](USER_GUIDE.md) |
| 下载对应系统的安装包、核对校验值 | [安装包目录](../packages/README.md) |
| 修改代码、测试和 Windows 打包 | [开发与构建](DEVELOPMENT.md) |
| Mac 打包、云端构建和人工验收 | [Mac 开发与构建](MACOS.md) |

| 查看柔化及界面参考 | [参考资料](SOFTENING_AND_UI_REFERENCES.md) |

程序源码保留在仓库根目录，脚本在 `scripts/`，测试在 `tests/`。
`packages/` 按版本和构建编号保存安装包索引，ZIP 和配套 TXT 说明由 GitHub Release 分发。
`builds/`、`releases/` 和 `test-artifacts/` 保存本地生成结果，不作为源码提交。
