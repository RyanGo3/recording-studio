# 土豆工厂 Mac 简易使用说明

适用系统：macOS 15 及以上。M 系列芯片用 arm64 包，Intel 芯片用 x86_64 包。

## 1. 安装

双击解压 ZIP，把 `PotatoFactory.app` 拖到「应用程序」，再双击打开。无需运行命令或安装 Python。

若提示无法验证开发者，确认是作者提供的包后，到「系统设置 → 隐私与安全性」点击「仍要打开」。

## 2. 录屏

打开「录屏与录音」→ 选「全屏」或「区域」→ 选择声音来源 → 开始录制 → 停止后等保存完成。

第一次弹出屏幕录制或麦克风权限时，点击允许；按提示退出并重新打开软件。

只录自己的讲话，声音来源选「仅外部」。

## 3. 录电脑声音

此功能需要先安装 BlackHole 2ch。在「音频 MIDI 设置」创建「多输出设备」，勾选扬声器／耳机和 BlackHole 2ch，再到系统声音设置把「输出」切到这个多输出设备。

随后在软件中选「系统声音」；还要录自己的讲话，就选「系统 + 外部」，系统默认输入保持为实际麦克风。

只要声音、不需要画面，选「仅录音」，保存为 MP3。此模式只录电脑声音。

## 4. 找成品

默认保存在「影片 → 土豆工厂」，也可在软件中更改目录。

转换、压缩或柔化：点左侧对应功能 → 添加文件 → 开始处理。

第一次先录 10 秒回放，确认画面和声音正常后再长录。
